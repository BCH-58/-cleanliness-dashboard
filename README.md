# لوحة متابعة النظافة

مشروع جاهز للنشر — مبني بـ React + Vite، ويستخدم Firebase Realtime Database
كقاعدة بيانات مشتركة (مشروع `m-bch`)، عشان أي مشرف يفتح الرابط من جواله
وبياناته تنعكس مباشرة عند المدير بدون تحديث يدوي.

## التشغيل محليًا (اختياري، للتجربة قبل النشر)

```bash
npm install
npm run dev
```

## النشر على Vercel

1. ارفع هذا المجلد على مستودع GitHub جديد.
2. من [vercel.com](https://vercel.com) اضغط **Add New → Project** واختر
   المستودع.
3. Vercel يكتشف تلقائيًا أنه مشروع Vite — اترك الإعدادات الافتراضية واضغط
   **Deploy**.
4. بعد النشر، من إعدادات المشروع في Vercel اذهب لتبويب **Domains** وأضف
   دومينك الخاص، واتبع تعليمات ربط سجلات DNS عند مزوّد الدومين.

## ملاحظات أمان مهمة

- قاعدة بيانات Firebase حاليًا مفتوحة القراءة والكتابة (`.read: true,
  .write: true`) عشان التطبيق يشتغل بدون نظام تسجيل دخول من Firebase نفسه.
  الحماية معتمدة بالكامل على رمز المدير ورمز كل مشرف داخل التطبيق، وليست
  حماية على مستوى قاعدة البيانات نفسها.
- إذا حبيت حماية أقوى لاحقًا، السطر التالي يوصف الوضع الحالي في تبويب
  **Rules** بقاعدة البيانات:
  ```json
  { "rules": { ".read": true, ".write": true } }
  ```
  يقدر مطوّر يطوّرها لاحقًا لتستخدم Firebase Authentication الحقيقي.
